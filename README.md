# Full Armor

**Spend 5 minutes a day to put on the full armor of God.**

Full Armor is a free Scripture memory app for all ages. It works in any phone or computer browser and can be added to your home screen like an app.

## Features

- **5-minute daily sessions** with spaced review, so each verse comes back right before you'd forget it
- **Drills that grow with you:** read aloud, word bank, put in order, fill the gaps, picture cues, first letters, then from memory
- **Picture cues:** key words become pictures to help verses stick
- **Scripture paths:** follow a sermon series (like Psalms 2-16), a whole book, the Foundations path, or Young Warriors for kids and youth
- **Your mansion:** place verses in the rooms of a mansion and walk through them in order (John 14:2)
- **The full armor of God:** earn XP and receive each piece from Ephesians 6
- **For every age:** larger text, read aloud, and tap-only drills
- **Built-in Bibles:** Berean Standard Bible and King James Version, both public domain

## Install it

Open the link and tap **Install** on the home screen. Full Armor goes on your home screen like any app and works offline.

- **Android and computers:** the Install button installs it in one tap (Chrome or Edge).
- **iPhone and iPad:** open the link in Safari, tap Share, then Add to Home Screen. The Install button shows these steps.

Your progress is saved on your own device.
